# Reposit Power

> Reposit Power is an Australian home-energy technology company (founded 2012, Canberra ACT) that builds the Reposit Controller — a local control device and cloud platform sitting on top of a household's solar, battery and meter — aggregates those households into a virtual power plant, and trades the stored energy into the National Electricity Market, paying the owner back as GridCredits under a "No Bill" guarantee. It publishes two anonymously readable OpenAPI contracts: a household-scope Customer API and a partner-scope Market (Fleet) API that can curtail and dispatch real household exports.

Generated by API Evangelist on 2026-07-27. Method: generated from apis.yml and this repository's artifacts — Reposit Power serves no llms.txt of its own (/llms.txt returns HTTP 404 on repositpower.com, api.repositpower.com, marketapi.repositpower.com and fleet.repositpower.com).

Key facts an agent should know before using these APIs:

- **Nothing is self-serve.** Every operational endpoint on both APIs returns HTTP 401 anonymously. The Customer API requires the credentials of an existing Reposit customer; the Market API requires an API key generated by hand inside the Reposit Fleet web app, which is issued to network, retailer and installer organisations under commercial contract.
- **The contracts are open; the data is not.** Both OpenAPI documents download anonymously with no login and no click-through. No row of data does.
- **The Market API commands real hardware.** `POST /api/curtailments`, `POST /api/curtailments/setpoint` and `POST /api/dispatches` change the real power output of real Australian homes. There is no idempotency key on any of them.
- **No regulatory mandate applies.** Reposit is not a designated Consumer Data Right energy data holder and not an accredited data recipient (verified against the ACCC CDR Register, 2026-07-27). Everything it publishes it publishes voluntarily.
- **No industry data standard is implemented.** No Green Button/ESPI, no Consumer Data Standards, no IEEE 2030.5/CSIP-AUS, no OpenADR, no OCPP/OCPI, no IEC CIM. The only sector identifier is the Australian National Metering Identifier (NMI).

## APIs

- [Reposit Customer API](https://api.repositpower.com/docs/): Household-scope REST API — login, list userkeys, and read one deployment's components, battery capacity, battery state of charge, solar generation, inverter real power, house consumption, grid-connection real power and earned GridCredits. OpenAPI 3.0.3, 11 operations, bearer JWT.
- [Reposit Power Market API](https://marketapi.repositpower.com/docs/): Partner-scope virtual-power-plant control plane used by fleet.repositpower.com — nodes, power stations, fleet telemetry, export curtailment and export dispatch. OpenAPI 3.0.1, 28 operations across 22 paths, non-expiring API key.

## SDKs

- [reposit (PyPI)](https://pypi.org/project/reposit/): The only first-party client library. Python, Apache-2.0, v0.4.0 released 2019-01-24, source at https://github.com/RepositPower/reposit-python-client (last commit 2021-03-29). Covers the household Customer API surface with a username/password connection; unmaintained, and it predates the documented `Reposit-Auth` bearer flow. There is no client library for the Market API in any language.
